Scenario Lab

      
Macro shocks · transmission channels · ranged impact estimates · all outputs tagged by epistemic tier

    

    

      
      
      
    

  


  
  

    

      Define Shocks
      Each shock has a magnitude and a confidence-in-the-shock-itself. The engine treats these as independent inputs (no implicit correlation assumed).
    

    

      
    

    

      

        Honest defaults:
        Elasticity ranges come from peer-reviewed studies (Hamilton 2003 oil-GDP, Bernanke/Gertler/Watson 1997 oil-equity, Edelstein/Kilian 2009 oil pass-through, etc.).
        Specific numbers are presented as ranges (e.g. ±2σ on the elasticity), not points.
        The engine does not claim "this will be like 1973 or 1990 or 2022" — it cites those episodes only to disclose where its parameter ranges come from.
      

    

  


  
  

    

      Timeline Horizons
      Different transmission channels resolve at different speeds. Energy-cost pass-through hits margins in 1-2 quarters; demand destruction takes a year+; capex reallocation takes 2-5 years.
    

    

      
      
      
      
      
      
      
    

  


  
  

    

      Current Market Context · live cross-asset state — not part of the shock, but informs the starting point

Global Trade Pulse

      
Trade flows, domestic production, consumption · logistics signals (ships, trucks, rail, planes, pipelines) via tradeable proxies · country-level snapshots beyond US-only

    

    

      
    

  


  
  

    

      LIVE
      = tradeable proxy (ETF/index price right now)
      MONTHLY
      = FRED/national statistics (1-2 month lag)
      QUARTERLY
      = IMF/World Bank/national accounts (3-6 month lag)
      STALE
      = older than 90 days, treat as last-known
    

    

      Important: trade data is fundamentally lagged. Customs filings publish 1-2 months after the trade. National GDP publishes 1 quarter after. Live logistics proxies (Baltic Dry, transportation ETFs, oil/gas movers) help fill the gap with tradeable signals, but they're proxies — not direct measurements. Treat proxies as directional, not as a substitute for the actual numbers when they arrive.
    

  


  
  


    
    

      
LIVE LOGISTICS PROXIES LIVE

      
Tradeable instruments that move with the underlying logistics activity. These are proxies — when BDRY rallies, dry bulk shipping is busy; when IYT diverges from S&P 500, the transport tape is telling you something different from the broad market.

Data Source URLs (one per line — Google Sheets URLs AND/OR raw GitHub URLs)

      
      

        Google Sheets: File → Share → Publish to web → choose sheet → CSV → Publish. Paste the URL.

Macro / FRED data base (optional — defaults to TRAPP2-1)

      
      

        Where the macro / FRED series live (data/macro/GDP.json, CPIAUCSL.json, the DGS* yield tenors, etc.) — used by the Macro Quad and the Treasury yield curve.

Supabase Auto-Backend (trading bot — optional, eliminates manual commits)

      
      
      

        
        
        
      

      
When set, the bot writes every trade to Supabase the instant it happens and reads them all on load — no manual export/commit, no human error. GitHub (TRAPP2-BOT) stays as backup. The anon key is meant to be public; a row-level-security policy on the bot_trades table guards writes. One-time setup: create a project at supabase.com, add a bot_trades table (id text primary key, trade jsonb, updated_at timestamptz default now()), enable an anon insert/update/select policy, then paste the URL + anon key here. See SUPABASE-SETUP notes for the exact SQL.
